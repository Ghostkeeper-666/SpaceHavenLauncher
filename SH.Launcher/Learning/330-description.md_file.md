# Moddig Basics: The "description.md" file

This is a simple file which uses the [Markdown Format](https://www.markdownguide.org/basic-syntax), and replaces the description of **info.xml** file in Space Haven Launcher
- It can be used as your mod's description on Steam or on Nexus Mods, so you are not wasting your time here
- This format is way better, because it allows you to better present the idea of your shiny new mod

The content could just be:
- Separate your topics using Headings / Titles
- Start by quickly describing what your mod does
- Explain any compatibility issues (if any)
- Describe how can the mod be parametrized with mod variables
- Afterwards go into further details (if any)

# Template

```
# DESCRIPTION

This mod introduces a new efficient toilet facility, which synthetizes human waste into ecologically correct ice cream

# COMPATIBILITY ISSUES

- The mod does not work in alpha and beta versions of Space Haven
- The mod is not compatible with any version of "Toxic Human Waste" mod

# MOD VARIABLES

The mod is fully configurable:
- You can set the amount of ice creams you get from each biomass unit
- You can set the nutritional properties of each new ice cream
- You may optionally mark this as "bad food"

# DETAILS

The classic ice cream device made from Hyperfuel is discontinued due to protection laws for pollution control of space ecosystems

The new rules aim to protect endangered alien species and new native tribes of rogue drones
...
```

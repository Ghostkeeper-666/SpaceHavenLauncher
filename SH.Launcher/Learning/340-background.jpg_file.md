# Moddig Basics: The "description.md" file

This is the file used as background for your mod in **Space Haven Launcher**
- Make it **2:1**, preferably ~**3840**x**1920** pixels
- Test drive it on **Space Haven Launcher**
- Compare the background brighness against other existing mods' backgrounds
- **Reduce the image brightness** if necessary, a good rule of thumb is to have max. color channel value = 127
- Avoid using any inadequate or provocative content, otherwise the mod could get red flagged

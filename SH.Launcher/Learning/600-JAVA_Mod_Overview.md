# Advanced Modding: JAVA mod Overview

Here we assume have good JAVA programming skills.

# Your main JAR file

Very important rules:
- Your JAR filename should preferably follow the mod's name, preferably without whitespaces and using Pascal case
- Put the JAR file in the root directory of your mod
- JAR files outside the root directory of your mod will be ignored

# How are mods JAR files used by Space haven Launcher?

When there is at least one JAVA mod:
- **Space Haven Launcher** never touches the original **spacehaven.jar**
- **Space Haven Launcher** generates its own **spacehaven.jar**
- **Space Haven Launcher** calls the JRE directly
- **VMArgs** and **MainClass** are **NOT** read from **config.json** (this file is ignored)
- These are auto-generated by **Space Haven Launcher** or customized by [System Core](tab://SystemCore) settings
- **Space Haven Launcher** uses a java agent to populate the class paths with full path to the mods' JAR
- **AspectJWeaver** java agent does its businees afterwards
- The last class path is the modified **spacehaven.jar**

# What is in the mods.json file?

This file is always generated by **Space Haven Launcher** and provides you valuable information:
- A few base directories (full path)
- All mods, listed by loading order
- Mod details, including 
- The **mod ID** assigned to your mod (*yes, the mod ID could be reassigned in case of conflicts*)
- All your **evaluated Mod Variable values**, defined by **info.xml**, with values provided by the player

The file also informs you about other mods:
- It lists enabled mods, ordered by build sequence
- It contains full evaluated details for each enabled mod
- It contains the name of the main JAR file: either **modifiedspacehaven.jar** or **spacehaven.jar**
- It lists the AOP libraries used in classPath (AspectJ)
- The player's operational system type: either **Windows**, **Linux**, or **OSX** (a.k.a. macOS)

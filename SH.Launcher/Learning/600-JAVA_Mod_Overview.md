# Advanced Modding: JAVA mod Overview

Here we assume you are a JAVA programmer. Otherwise, you must first learn how to program using JAVA.

# Your main JAR file

Very important rules:
- First of all, avoid at all costs using multiple JAR files, as this just makes things more complicated
- Your JAR filename should follow the mod's name, removing any whitespace, preferably using Pascal case
- Put the JAR file in the root directory of your mod

# How are mods deployed?

Since your JAR file is always deployed to the game's spacehaven.jar directory...
- You can easily get the game's JAR directory
- From there you can parse useful information the **config.json** and **mods.json** files

When there is at least one XML mod:
- **Space Haven Launcher** generates a new **modifiedspacehaven.jar** file
- The **modifiedspacehaven.jar** is deployed and used instead of the original **spacehaven.jar** file
- **Space Haven Launcher** never touches the original **spacehaven.jar** !!!
- This facilitates the detection of a new **spacehaven.jar** file
- It also allows the player to close **Space Haven Launcher** while playing the game without severe repercussions

# What is in the mods.json file?

This file is always generated by **Space Haven Launcher** and provides you valuable information:
- **Full path** to your Mod's files
- The **mod ID** assigned to your mod (*yes, the mod ID could be reassigned in case of conflicts*)
- All your **evaluated Mod Variable values**, defined by **info.xml**, with values provided by the player

The file also informs you about other mods:
- It lists enabled mods, ordered by build sequence
- It contains full evaluated details for each enabled mod
- It contains the name of the main JAR file: either **modifiedspacehaven.jar** or **spacehaven.jar**
- It lists the AOP libraries used in classPath (AspectJ)
- The player's operational system type: either **Windows**, **Linux**, or **OSX** (a.k.a. macOS)
